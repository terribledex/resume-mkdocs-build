# Структура проекта - личный сайт на базе mkdocs с темой а-ля catppuccin (latte&frappe)

```
resume/
├── mkdocs.yml                    # Главный конфигурационный файл
├── docs/                         # Папка с контентом
│   ├── main.md                   # Главная страница
│   └── about.md                  # О себе
└── docs/
    ├── stylesheets/              # CSS файлы
    │   ├── catppuccin.css        # Цветовая схема Catppuccin
    │   └── extra.css             # Дополнительные стили и анимации
    └── javascripts/              # JavaScript файлы
        └── extra.js              # Дополнительная интерактивность
```

## Установка и настройка

### 1. Установите необходимые пакеты:

```bash
pip install mkdocs-material
pip install mkdocs-minify-plugin
pip install mkdocs-glightbox
```

### 2. Создайте файлы:

1. **mkdocs.yml** - используйте конфигурацию выше
2. **docs/stylesheets/catppuccin.css** - скопируйте CSS для цветовой схемы
3. **docs/stylesheets/extra.css** - скопируйте дополнительные стили
4. **docs/javascripts/extra.js** - скопируйте JavaScript код

### 3. Создайте контент:

Создайте markdown файлы в папке `docs/` для каждой страницы навигации.

### 4. Запустите локальный сервер:

```bash
mkdocs serve
```

### 5. Соберите и разверните:

```bash
mkdocs build
mkdocs gh-deploy  # для деплоя на GitHub Pages
```

## Особенности темы

### 🎨 Цветовая схема Catppuccin
- **Latte** (светлая) - мягкие пастельные тона
- **Frappe** (темная) - уютные приглушенные цвета
- Автоматическое переключение по системным настройкам

### ✨ Графические элементы
- Плавные анимации появления контента
- Парящие частицы в header
- Эффект печатной машинки для заголовков
- Ripple эффект для кнопок
- Градиентные переходы
- Sparkle иконки для заголовков
- Красивые разделители с декорацией

### 🎮 Интерактивность
- Индикатор прогресса чтения
- Smooth scroll навигация
- Анимации при скролле
- Пасхалка с Konami Code
- Конфетти эффект (вызов: `triggerCelebration()`)
- Hover эффекты для всех интерактивных элементов

### 📱 Адаптивность
- Полная поддержка мобильных устройств
- Отключение сложных анимаций для пользователей с `prefers-reduced-motion`
- Адаптивная типографика

### 🛠️ Дополнительные возможности
- Подсветка синтаксиса с цветами Catppuccin
- Поддержка Mermaid диаграмм
- Lightbox для изображений
- Минификация HTML
- Расширенный поиск
- Копирование кода одним кликом

## Примеры использования

### В markdown файлах можно использовать:

```markdown
!!! note "Заметка"
    Красивая заметка с анимированной иконкой

!!! tip "Совет"
    Полезный совет с sparkle эффектом

!!! warning "Внимание"
    Важное предупреждение
```

### Эмодзи в навигации:
Эмодзи в названиях страниц получат дополнительные hover эффекты.

### Код блоки:
Автоматически получают красивое оформление в стиле macOS с цветными кнопками сверху.
